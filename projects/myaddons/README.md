# Custom Odoo 17 Addons & Modules

This directory contains the custom Odoo 17 modules developed as part of this project:

| Module | Description | Core Technologies |
| :--- | :--- | :--- |
| **[`my_hospital`](./my_hospital)** | Hospital & Healthcare ERP (Patients, Doctors, Appointments, Prescriptions, Wizards, QWeb Reports, Pivot/Graph Analytics) | Python, Odoo ORM, Mail Thread, QWeb |
| **[`owl_dev`](./owl_dev)** | Modern Web Client Frontend Components & Widgets | JavaScript (OWL 2.0), SCSS, XML Templates |
| **[`qweb_app`](./qweb_app)** | Advanced QWeb PDF Reporting Templates & Styling | QWeb Engine, XML, Wkhtmltopdf |
| **[`testapp`](./testapp)** | Odoo ORM Mechanics, Decorators (`@api`), Constraints & Workflow Automation | Python, PostgreSQL Constraints |

For full setup instructions and project documentation, please refer to the [Root README](../../README.md).
